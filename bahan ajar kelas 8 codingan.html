Selamat Datang!

Selamat belajar Informatika! Pada bab ini kita akan mempelajari tentang sistem komputer dan bagian-bagian yang menyusunnya.

Tujuan Pembelajaran

Setelah mempelajari materi ini, peserta didik mampu:
  1. Menjelaskan pengertian sistem komputer.
  2. Mengidentifikasi perangkat keras (hardware).
  3. Menjelaskan fungsi perangkat lunak (software).
  4. Mengidentifikasi peran pengguna komputer (brainware).

Apa Itu Sistem Komputer?

Sistem komputer adalah sekumpulan komponen yang saling bekerja sama untuk menerima data, mengolah data, menyimpan data, dan menghasilkan informasi.

🖥️

Hardware

Perangkat keras komputer.
💿

Software

Perangkat lunak komputer.
👨‍💻

Brainware

Manusia sebagai pengguna.

Pengertian Sistem Komputer

Sistem komputer merupakan gabungan dari tiga komponen utama yang saling berhubungan, yaitu hardware, software, dan brainware.

Contoh sederhana: Ketika kita mengetik tugas menggunakan komputer:
  • Keyboard digunakan untuk memasukkan tulisan (hardware).
  • Aplikasi Microsoft Word digunakan untuk mengetik (software).
  • Siswa yang mengetik tugas disebut pengguna (brainware).

Bagaimana Komputer Bekerja?

  1. Input: komputer menerima data.
  2. Process: komputer mengolah data.
  3. Output: komputer menampilkan hasil.
  4. Storage: komputer menyimpan data.

1. Hardware (Perangkat Keras)

Hardware adalah seluruh bagian fisik komputer yang dapat dilihat dan disentuh.

Contoh Hardware

⌨️

Keyboard

Memasukkan huruf, angka, dan simbol.
🖱️

Mouse

Menggerakkan pointer dan memilih menu.
🖥️

Monitor

Menampilkan gambar dan informasi.
🖨️

Printer

Mencetak dokumen ke kertas.
🔊

Speaker

Mengeluarkan suara.
💾

Hard Disk

Menyimpan data dan file.
🧠

Processor

Mengolah instruksi dan data.
📷

Webcam

Mengambil gambar dan video.
Kesimpulan: Hardware merupakan bagian komputer yang memiliki bentuk fisik.

2. Software (Perangkat Lunak)

Software adalah kumpulan program atau instruksi yang digunakan untuk menjalankan komputer. Software tidak dapat disentuh secara fisik.

Contoh Software

🪟

Windows

Sistem operasi komputer.
🐧

Linux

Sistem operasi komputer.
📝

Microsoft Word

Membuat dan mengedit dokumen.
📊

Microsoft Excel

Mengolah angka dan tabel.
🌐

Google Chrome

Menjelajahi internet.
🎨

Paint

Menggambar dan mengedit gambar sederhana.
Kesimpulan: Software merupakan program yang memberikan perintah kepada komputer agar dapat bekerja.

3. Brainware (Pengguna Komputer)

Brainware adalah manusia yang menggunakan, mengoperasikan, mengelola, atau mengembangkan sistem komputer.

Contoh Brainware

👨‍💻

Programmer

Membuat dan mengembangkan program komputer.
🧑‍🏫

Operator

Mengoperasikan komputer untuk pekerjaan tertentu.
🧑‍🔧

Teknisi

Memperbaiki dan merawat perangkat komputer.
👩‍💼

Administrator

Mengelola sistem dan data komputer.
🧑‍🎓

Pengguna

Menggunakan komputer untuk belajar dan bekerja.
Kesimpulan: Brainware adalah manusia yang berperan dalam penggunaan dan pengelolaan komputer.
